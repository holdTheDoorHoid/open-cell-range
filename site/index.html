About this simulation — read before you start

This is a pure simulation. The radio world is a data structure in memory. Nothing is transmitted, received, or measured — there is no SDR, no baseband, no SIM, no antenna, and no code path that could drive any of those.

It is built on published, standardised knowledge: the GSM one-way-authentication problem, the LTEInspector / aLTEr family of pre-authentication weaknesses, and the 5G-AKA linkability results — all documented in open standards and peer-reviewed research. Subscriber keys are the published 3GPP test vectors; no real subscriber keys exist anywhere in this project.

It is defence-first: every attack drill has a matching defender drill, and the same passive-monitor logic that raises a finding here is what a real detector (like Rayhunter) would conclude from the same air.
